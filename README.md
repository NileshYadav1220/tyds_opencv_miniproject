# 12 Computer Vision Mini Projects — Easy Level

Each project contains simple Python code, `requirements.txt`, and a `README.md`.

## Projects
1. Traffic sign classification (CNN)
2. Plant disease classification (MobileNetV2)
3. Handwritten OCR (EasyOCR)
4. Facial emotion recognition (DeepFace)
5. Food/general image classification (MobileNetV2)
6. Multi-object tracking (OpenCV)
7. Image captioning (BLIP)
8. Gesture/hand landmark recognition (MediaPipe)
9. Visual question answering (BLIP)
10. Face age estimation (DeepFace)
11. Human pose estimation (MediaPipe)
12. Industrial anomaly detection (Isolation Forest)

## General notes
- Use Python 3.10 or 3.11 where possible.
- Install each project's requirements inside its own virtual environment.
- Some models download pretrained weights on first run.
- The two training projects require you to download and arrange a dataset.
- These are educational mini-project baselines. Predictions can be wrong.
